Dev Log · Uncharted Rally

Uncharted Rally #0006

16 March 2026 / 2 min read / Oliver Creese

Custom Chaos vehicle setup, car customisation, using Unreal 5.7's new procedural tools for vegetation, and setting up physical materials alongside Chaos vehicle for realistic driving physics.

Custom Chaos Vehicle Pawn

I created my own setup for a car using the Chaos wheeled vehicle component that works with controller. It has a dynamic camera setup so that it will naturally interpolate the camera back to its relative position when the vehicle is in motion. When stopped, the player can look around the car freely. The vehicle can be controlled by keyboard or controller. I set up some base values and did a lot of testing on the torque curves and other engine modifications to find something that resembled a rally car. The pawn inherits from a C++ parent class I made that exposes some of the component class attributes that aren't available in Blueprint for the car customisation.

Car Customisation

The player can freely customise their car to meet their needs. There are several options for customisation: suspension stiffness, tyre compound, drivetrain, chassis and skin. This allows the player to change their car setup to meet the needs of the conditions, terrain and level of gravity. The parent Chaos vehicle pawn class accesses the wheel components to change attributes such as friction and suspension spring rate to affect the handling. Each tyre compound has a lateral slip graph associated with it that drastically changes how the car handles when taking corners.

Alongside the vehicle's physics setup, I am additionally using physical materials to change how the cars drive on different surfaces. On the track, the spline mesh that serves to texture the terrain through the RVT is also being used to provide a collision surface along the track for the correct friction properties for the surface.

Unreal 5.7 Features

I am using the procedural vegetation editor alongside the new Nanite foliage system housed for Quixel's Megaplants assets to create my own custom foliage that is more performant. The PVE allows you to adjust things like how much gravity affects the plant's structure, trunk and branch size, as well as being able to change the leaves and amount of leaves. This system creates a skeletal mesh which pairs with the new wind system that is much more performance friendly. The assets also use the new Nanite foliage voxelisation, which further reduces quad overdraw by rendering the asset with voxels that are easier to compute and look better at a distance.
