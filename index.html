Skills

The engines, languages and tools I work with — hover or tap a card for the details.

Unreal Engine

I have extensive experience developing in Unreal Engine 5 across C++ and Blueprint, working on projects spanning open-world RPGs, first-person shooters, and racing simulations. My most recent work includes combat systems using input-based target selection, weapon and resource based upgrade systems, and procedural generation via the Procedural Mesh Component and a chunking system. I have solid experience with animation programming through Anim Blueprints and procedural techniques for weapon recoil. My broader focus is on scalable architecture — using delegates, Blueprint Interfaces, and proper class inheritance hierarchies to keep systems decoupled, maintainable, and easy to iterate on.

Unity & C#

I have experience developing in Unity across a range of genres including party games, survival horror, and 2D arcade games — one of which won a game jam and is published on Steam. My work includes multiplayer implementation using Netcode for GameObjects and Unity Sessions, managing lobby state and scene transitions across a replicated multiplayer environment. I have implemented a replicated active ragdoll system driven by ConfigurableJoints with a separate hidden mesh for animation blending and physics-based player interactions. I have also built custom AI systems using NavMesh with state machines managing multiple behavioural states, including systems where AI behaviour and presentation change dynamically at runtime based on game state.

C++ & OOP

I have extensive experience writing C++ across multiple environments and abstraction levels. Within Unreal Engine 5 I work regularly in C++ for building complex gameplay systems that lie beyond the capabilities of Blueprints, with marginal performance gains and the benefit of manual memory management. I have also worked with low-level in-house engines at my university, building games from scratch in both 2D and 3D contexts — including physics implementations such as Hooke's law for surface simulation, enemy pathfinding, animation systems, and weapon systems with upgrade pipelines, all without the abstractions of a commercial engine. Alongside practical experience I have been studying modern C++ in depth, including memory management, smart pointers, and parallelisation — with a focus on real-world use cases such as multithreaded chunk loading for large-scale procedural environments.

OpenGL API

I have experience building rendered scenes in OpenGL, working directly with the graphics pipeline and writing custom shaders. My work covers techniques including heightmap-based terrain tessellation, shadow mapping, light attenuation, water rendering and reflective materials. I have also implemented creative solutions such as simulating clouds using a particle system with layered opacity and alpha blending.

Autodesk Maya

I use Autodesk Maya for creating and preparing game-ready 3D assets — modelling, UV unwrapping and basic rigging — and for getting animations ready to import into Unreal Engine and Unity.

Git Version Control

I use Git for version control across all of my projects, working with branching workflows when collaborating with teammates and hosting my repositories on GitHub.
